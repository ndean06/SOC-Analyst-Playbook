# Splunk SOC Playbooks

Reusable procedures, deployment checklists, configuration templates, and troubleshooting guides for Splunk SOC operations.

## MITRE ATT&CK Dashboard Resources

- [Standard Operating Procedure](MITRE-Dashboard-SOP.md)
- [Deployment Checklist](MITRE-Dashboard-Checklist.md)
- [Navigation XML Template](navigation-template.xml)

### How to Use

1. Review the SOP before configuring a new environment.
2. Copy the deployment checklist for each setup.
3. Customize the navigation XML for the target environment.
4. Verify dashboard permissions, URLs, and functionality.
5. Document any troubleshooting findings.

**Note:** Keep the original checklist unchanged so it
can be reused for future deployments.
